Exploration E of the post-reset Home explorations lives at `design/v2/explore/home-e.jsx` + `design/v2-he.html` (siblings own home-a/home-b). Visual system: broadsheet newspaper — double-rule masthead, full-bleed ultramarine hero band (#1B2A9E), vermilion correction-box notice, 31-day ledger strip, three numbered hairline columns, folio footer. Ground is cool paper #F5F5F0 / press-ink #101118 (deliberately NOT the cream+serif AI-editorial reflex).

**Why:** the user kicked the Peacock & Slate system ("looks basic… keka looks so clean"); parallel free explorations replace variation-on-tokens work. Key reusable find: **Rozha One (Google Fonts, ITF) natively covers Latin AND Devanagari** — one fatface display voice in both languages, which dissolves the EN/hi display-pairing problem entirely (no Latin-display + Devanagari-fallback mismatch in hero type). Text pairing: Schibsted Grotesk (Latin) / Mukta (Devanagari); figures Spline Sans Mono with Mukta fallback for hi mono strings (Spline has no Devanagari).

**How to apply:** if an editorial/display direction survives review, reach for Rozha One (or ITF siblings with dual-script coverage) before inventing a two-face pairing. Also: the impeccable design hook flags a thick one-side accent border on a card (`side-tab`) as an AI-tell — a full 2px box rule (newspaper notice box) reads better and passes; prefer that shape for alert/notice panels.
