## Anti-Patterns Verdict

LLM: Does not read as AI-made. Copy, domain modelling and state design are specific and human. Two AI-grammar leftovers: KPI hero-metric strips with tiny uppercase tracked labels (HR Home, Staff register), and the rounded identical card grid on Employee Home, which contradicts PRODUCT.md's "the register is the product, not a card dashboard".

Detector: static scan saw only the HTML shell (1 finding: overused-font). In-page injection on 5 screens (60 findings): tiny-text 11.5px (50+ hits, worst on Payroll Home, 20), overused-font Inter/Roboto (deliberate per DESIGN.md 2026-10-12, low priority), cream-palette page bg (deliberate brand), line-length ~101ch (Payroll Home), cramped-padding (HR Home), low-contrast 1.0:1 #f6e9dc on #f6e9dc on every page (could not locate the element; unconfirmed, possibly hidden/decorative).

## Priority Issues

1. [P1] Phone experience is not designed. At 390px the desktop rail stays (~21% of width), cards clip off the right edge, the Home "Your day" date collides with its status pill, stats truncate. No mobile/Flutter screens exist in design/. Primary users are desk-less teachers on phones; Keka, Darwinbox and greytHR all lead with a mobile app (clock-in, leave, payslip). Fix: below 768px swap the rail for a bottom tab bar (Home, Attendance, Leave, Payslips, More), single column, header ≤2 lines; then design the Flutter ESS in v3 tokens. → /impeccable adapt

2. [P1] No global way to find or be told things. No search/command bar, no notification bell/inbox, no avatar menu. HR rail runs 17+ items, Payroll 16, with repeated icons and 11.5px labels. Keka: ⌘K "Search employees or actions", bell, Inbox rail item, and a "Me" hub with sub-tabs keeping the rail at 8. Fix: top bar with people+actions search, unified approvals inbox, avatar menu (profile, campus, language, sign out); rail ≤8 sections with sub-tabs; labels ≥12px. → /impeccable layout

3. [P1] Decorative charts that misinform. Multi-colour stacked bars under KPI strips sum unlike quantities (HR Home: overdue docs + joiners + exits; Staff register: probation/contracts/notice against 214). Plus the KPI-strip pattern PRODUCT.md bans. Fix: delete the stacked bars; fold counts into the "What needs you" queue (already the stronger pattern) or give each count its own denominator. → /impeccable distill

4. [P1] Hindi is absent. 75 English string blocks, 0 Hindi; DESIGN.md says "English only", contradicting PRODUCT.md "Bilingual by construction" and the guard-i18n rule. Devanagari line-heights, wrapping and the 11.5px labels have never been tested on real screens. Fix: get a ruling; if bilingual stays, add hi strings for the employee surfaces first and screenshot both. → /impeccable harden

5. [P2] Duplication and inconsistency. Web clock-in appears twice on My Attendance and again on Home; Payroll Home and Payroll run show the same campus × amount × status; Requests/Helpdesk/Adjustments share one icon, Registers/Reports/Documents/Doc control another; breadcrumb's second segment is the org name, not a path. Fix: one clock-in per screen, Payroll Home = only what is blocked, distinct icons per rail item. → /impeccable polish

## Persona Red Flags

Ananya (PGT teacher, phone between classes): opens the web link on her phone and sees a rail eating a fifth of the screen, a clipped "Not clocked in yet" pill, and a 3-line greeting before anything actionable. Cannot sign in with Google Workspace or OTP; must type a CAPTCHA every login.

Meera (HR operator, power user): wants to jump to "Vikram Sen" — no search; scans 17 rail icons where 4 look the same. 11.5px captions all day. Approvals live in per-module queues, not one inbox.

Sam (accessibility): state is never colour-only (good: icon + word everywhere). Risks: 11.5px text widespread; the stacked bars convey nothing to a screen reader; unconfirmed 1:1 contrast element on every page.

## Minor Observations

- [P2] Login: CAPTCHA on every sign-in; no SSO (Google Workspace / Microsoft) or mobile OTP, which schools and desk-less staff expect. Show CAPTCHA only after failed attempts.
- [P3] Side-stripe border-left on the leave reason quote (Leave → LR-0219) — absolute ban; use a tinted block.
- [P3] Decorative arc/line motif behind content on every page competes with data on operator screens.
- [P3] Payroll run: oversized month carousel and an empty lower half; a compact month picker + history table would do.
- [P3] Payroll Home intro runs ~101ch per line.
- [P3] Cream page bg + terracotta is on-brand but a saturated 2025–26 look; consider a near-white content surface on data-dense operator screens.
- [P3] Docs drift: impeccable SKILL.md "Tenure project config" still names Greenboard & Chalk + IBM Plex; DESIGN.md Mulberry note says "Warm Grotesk" though v3 type is Inter + Roboto.
- [P3] The canvas role-switcher pill overlays the bottom of every screen — fine for demos, must never ship.

## What's Working

- Queue-first operator homes. "What needs you" (state + count + oldest age + open) beats Keka's widget dashboard and matches Darwinbox's inbox idea, scoped per role.
- School-native modelling nobody else has: "Classes you have been asked to cover", academic-session month pills, "Earned leave — not for teaching staff, covered by vacations", per-lecture guest faculty, multi-campus switcher.
- Payslips: in-app PDF view, PAN/UAN/bank masked (Keka leaves bank unmasked), net pay in words, Indian digit grouping, password hint. Plain-language status copy; state never by colour alone.
